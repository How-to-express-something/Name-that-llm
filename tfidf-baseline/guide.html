用 TF-IDF 从一段回答识别模型

任务是根据单段文字，从 18 个候选大模型中识别作者。词级 TF-IDF + LinearSVC 已完成比赛的隐藏测试重跑和公开评分。

首次提交的 Public Score 为 0.273（27.30%）。 分数由参赛者反馈。同一模型按题目分组的本地五折平衡准确率为 26.45%，公开榜高 0.85 个百分点。两次评估结果接近，支持词汇特征在新题目上仍有识别力。公开榜覆盖隐藏集的一部分，最终成绩以私榜为准。

如何模拟遇到新题目

本次训练集有 2,699 段不同文本，来自 150 个提示词。17 个模型各有 150 段，claude-fable-5 有 149 段。由于隐藏测试的题目没有在训练集出现，先对排序后的 150 个 prompt_id 固定随机种子 42 分成五组。每轮用 120 题训练，30 题验证，同一道题的所有回答一起留出。词表、逆文档频率和分类器均只用当折训练文本拟合。汇总五折预测后，每段文字都有一次折外预测。官方数据说明

主模型将文本转小写，提取单词与相邻双词组，保留至少在两篇训练文本中出现的特征。词频经对数缩放，与逆文档频率相乘后对每篇文档做 L2 归一化。用这些稀疏向量训练线性支持向量分类器 LinearSVC(C=1)，输入只取 text。下表的对照使用相同的数据分组和分类器。

只保留 scikit-learn 英语停用词表中的常用词，平衡准确率仍有 19.89%，高于随机猜测 14.34 个百分点。代词、冠词和介词等常被过滤掉的词，本身就包含跨题目可用的模型线索。

只用单词比加入相邻词对高 0.63 个百分点，同题配对重抽样的差值区间为 −0.70 至 +1.93 个百分点，优势方向仍有不确定性。改用 3–5 字符片段则比主模型高 4.00 个百分点，差值区间为 +2.33 至 +5.71 个百分点。字符特征可以保留词内片段、标点及空白，也能编码词汇；这个对照支持更细粒度的表面特征有用，各因素的独立贡献尚未拆分。

主模型五折分别为 24.63%、28.70%、24.07%、29.27%、25.56%。表中的区间按 150 个题目有放回重抽样 5,000 次，每个题目的全部折外预测一起抽取，取 2.5% 和 97.5% 分位数。配对差值在每次重抽样中使用相同题目。区间反映这批验证题目的抽样波动；隐藏集分布差异和重新训练带来的波动另计。

用信息量看折外预测

本地 18 个真实标签的经验熵约为 4.17 bit/段。把五折产生的预测标签与真实标签交叉计数，得到经验互信息 0.89 bit/段。换句话说，在这张交叉表里，知道分类器猜了哪个模型后，真实标签的平均剩余不确定性约为 3.28 bit。即使一次没有猜中，该预测也可能缩小候选范围。

计算使用 results/confusion.csv 归一化后的联合频率，I = Σ p(i,j) log₂[p(i,j) / (p(i)p(j))]。有限样本会让经验互信息偏高。在每个题目内随机重排预测标签 1,000 次，保持模型预测的频数，得到的均值仍为 0.076 bit。0.89 bit 描述本批硬预测与标签的关联；完整 TF-IDF 向量可包含更多信息，隐藏测试集上的数值需要另行估计。

用折外预测复算互信息和随机对照

在项目目录运行以下 Python 代码。固定真实标签，将每个题目内的预测随机打乱；这样每题的预测模型数和各类频数都保持不变。

import numpy as np
import pandas as pd
from sklearn.metrics import mutual_info_score

oof = pd.read_csv("results/oof.csv")
y = oof["model"].to_numpy()
pred = oof["word_12"].to_numpy()
groups = list(oof.groupby("prompt_id", sort=True).indices.values())
rng = np.random.default_rng(42)
print(mutual_info_score(y, pred) / np.log(2))
controls = []
for _ in range(1000):
    shuffled = pred.copy()
    for group in groups:
        shuffled[group] = rng.permutation(pred[group])
    controls.append(mutual_info_score(y, shuffled) / np.log(2))
print(np.mean(controls))

在 Kaggle 运行隐藏测试

  1. 登录比赛账号并接受规则。打开比赛的 Code 标签，点击 New Notebook，通过 File → Import Notebook 导入本机的 tfidf-baseline.ipynb。
  2. 确认 Notebook 的输入已挂载 name-that-llm 比赛数据。如果尚未挂载，用 Add Input 添加此比赛的数据源。在设置中关闭 Internet 并使用 CPU。赛方限制单次运行最多 9 小时。
  3. Notebook 从 /kaggle/input/competitions/name-that-llm/train.csv 拟合分类器，再逐行预测 /kaggle/input/competitions/name-that-llm/test.csv，写入 /kaggle/working/submission.parquet。输出只含字符串列 id 和 model，必须覆盖当次测试集的全部 ID，各一次；每个模型名须与训练标签完全一致。
  4. 选择 Save Version → Save & Run All。运行成功后，在该版本查看器的 Output 中选择 submission.parquet 并点击 Submit to Competition。Kaggle 会用约 4,000 段隐藏文本替换交互样例并从头重跑已保存的版本。
  5. 在比赛页 Submissions 中查看该次运行的状态；评分成功后可以看到 Public Score。也可用已认证的 CLI 提交某个运行成功的 Notebook 版本并查询提交列表，替换命令中的账号、Notebook 标识和版本号即可。
